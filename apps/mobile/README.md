# Project Coffee Bean: mobile app

React Native app built with Expo (SDK 58) and Expo Router. It browses the catalogue offline from a
bundled SQLite snapshot.

## Run it

Requires Node.js 22.13 or newer.

```bash
npm install
```

```bash
npx expo start
```

Scan the QR code with Expo Go on Android or iOS, or press `w` for the web preview.

## Layout

| Path | What |
| --- | --- |
| `src/app/` | Screens (file-based routes). `(tabs)/` holds the four tabs: Discover, Roasters, Beans, Taste |
| `src/components/ui.tsx` | Shared building blocks |
| `src/db.ts` | Database asset, query hook and shared SQL |
| `src/theme.ts` | Colours and type, taken from the logo |
| `assets/data/coffee.db` | Generated. Rebuild with `npm run build:sqlite` at the repository root |

The catalogue database is read-only and is copied to the device once per data version
(`src/db-version.ts` is generated by `npm run build:sqlite`; do not edit it). Anything a user creates
(tasting logs are planned) must go into a separate database: see `docs/adr/0003-tasting-logs.md`.
