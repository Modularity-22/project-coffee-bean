# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's
**Security → Report a vulnerability** on this repository ([direct link](https://github.com/Modularity-22/project-coffee-bean/security/advisories/new)).
You should get a reply within seven days.

Useful to include: what is affected (the app, a tool, the build pipeline), how to reproduce it, and
the impact you expect.

## Scope

- The mobile app in `apps/mobile`
- The build and validation tools in `tools/`
- The repository's CI workflows

Wrong or outdated data about a company is not a security issue: open a **Data correction** issue.

## Supported versions

Only the latest release and the `main` branch receive fixes.
