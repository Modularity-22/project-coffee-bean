# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/Modularity-22/project-coffee-bean/discussions).
- **Something is broken:** open a Bug report issue.
- **Data is wrong or missing:** open a Data correction or Add a roaster issue.
- **You represent a listed company:** open a Data correction issue and say so; these are handled first.
- **Security problems:** see [SECURITY.md](SECURITY.md).

This project is run by volunteers, so replies can take a few days.
